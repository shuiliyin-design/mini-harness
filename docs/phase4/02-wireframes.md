# Low-fidelity Mobile Wireframes

以下 wireframe 表达目标 IA 和产品语言，不表示当前 HTTP/UI 已实现。现有详情图以 BRIEFING 为例；CONDITION/EVENT
沿用同一导航与 confirmation，不复用条目摘要布局。

## 1. Home / Updates

```text
┌────────────────────────────┐
│ 更新                  ＋关注 │
├────────────────────────────┤
│ 今天                       │
│ ┌────────────────────────┐ │
│ │ AI 行业动态        8 分钟前│ │
│ │ 新模型工具调用能力正在收敛… │ │
│ │ 3 条更新 · 约 4 分钟阅读    │ │
│ │ [查看更新]                  │ │
│ └────────────────────────┘ │
│                            │
│ 正在准备                   │
│ ┌────────────────────────┐ │
│ │ 开源数据库               │ │
│ │ 已关注，首篇资讯正在准备   │ │
│ └────────────────────────┘ │
├────────────────────────────┤
│ 更新        关注        我的 │
└────────────────────────────┘
```

空状态：

```text
┌────────────────────────────┐
│ 还没有更新                  │
│ 告诉我一个想持续关注的主题， │
│ 我会先和你确认范围。         │
│ [创建第一个关注]             │
└────────────────────────────┘
```

```text
│ [继续]                      │
└────────────────────────────┘
```

## 3. Conversation

```text
┌────────────────────────────┐
│ ‹ 保存并退出   完善关注范围   │
├────────────────────────────┤
│ 你  想关注 AI Agent 和工具…  │
│                            │
│ 助手                         │
│ 更看重模型发布、开发工具，    │
│ 还是实际落地案例？           │
│                            │
│ 你  模型发布和开发工具。      │
│                            │
│ 助手                         │
│ 只关注重要发布，还是也包括    │
│ 日常应用案例？                │
│                            │
│ ┌────────────────────────┐ │
│ │ 输入回答…                │ │
│ └────────────────────────┘ │
│ [发送]                      │
└────────────────────────────┘
```

同一 composer 根据 server status 反复出现；没有 “第 2/3 问” 或 `asked_once`。

## 4. Definition Confirmation

```text
┌────────────────────────────┐
│ ‹ 返回       确认关注范围    │
├────────────────────────────┤
│ AI 行业动态                 │
│                            │
│ 你告诉我的                   │
│ 关注对象  AI Agent 行业动态   │
│ 重点方向  模型发布、开发工具   │
│                            │
│ 系统默认设置                 │
│ 语言      中文               │
│ 每期上限  600 字 / 5 条       │
│ 通知      在产品内查看         │
│                            │
│ 确认后会创建持续关注。        │
│ [调整]                      │
│ [确认并开始关注]              │
└────────────────────────────┘
```

用户没有说过的默认值不得出现在“你告诉我的”。旧 Definition 无法证明来源时显示为“系统理解（请确认）”，不追认成
用户选择。

提交成功：

```text
┌────────────────────────────┐
│ ✓ 已开始关注 AI 行业动态     │
│ 正在开始关注，有更新后会出现在 │
│ “更新”中。                   │
│ [返回更新]  [查看关注详情]     │
└────────────────────────────┘
```

## 5. Feed Detail

```text
┌────────────────────────────┐
│ ‹ 更新       AI 行业动态  ⋯  │
├────────────────────────────┤
│ 今天 · 3 条 · 已更新         │
│                            │
│ 1. 模型工具调用的新变化       │
│    两句摘要……                │
│    来源 A · 2 小时前          │
│    为什么推荐 ›              │
│    [多来点] [少来点] [收藏]   │
│                            │
│ 2. 开发工具发布……            │
│    …                        │
├────────────────────────────┤
│ 关注范围                     │
│ Agent、模型发布、开发工具      │
│ [查看历史] [管理关注]          │
└────────────────────────────┘
```

“为什么推荐”展开：

```text
与你的关注匹配：开发工具
你最近对“Agent”选择过 2 次“多来点”
内容发布于今天，且此前未推荐过
```

这些句子必须能追溯到 deterministic score/profile facts。

## 6. Subscription Management

```text
┌────────────────────────────┐
│ ‹ AI 行业动态   管理关注     │
├────────────────────────────┤
│ 状态       正在关注           │
│ 频率       每天               │
│ 通知       暂不通知           │
│ 关注范围   Agent、模型发布…    │
│                            │
│ [调整关注范围]                │
│ [暂停关注]                    │
│                            │
│ 历史                         │
│ 8 月 27 日  3 条更新           │
│ 8 月 26 日  未发现重要变化      │
└────────────────────────────┘
```

暂停态保留 history，并显示 `[恢复关注]`；material edit 进入 clarification + confirmation，不直接 patch 当前
definition。

## 7. Failure States

准备失败但 subscription 已成立：

```text
┌────────────────────────────┐
│ AI 行业动态 · 正在关注       │
│                            │
│ 这次检查暂时没有完成。         │
│ 你的关注仍然有效。            │
│ [稍后再试] [管理关注]          │
└────────────────────────────┘
```

结果不明确、禁止盲重试：

```text
┌────────────────────────────┐
│ 这次更新的状态暂时无法确认。   │
│ 为避免重复内容，我们不会自动重做。│
│ [返回更新]                    │
└────────────────────────────┘
```

Definition 不完整：

```text
┌────────────────────────────┐
│ 还没能确认你的关注范围。       │
│ 已保存你输入的内容。           │
│ [继续完善] [重新开始]          │
└────────────────────────────┘
```

不支持的请求：

```text
┌────────────────────────────┐
│ 目前还不能可靠地完成这个关注目标。│
│ 你可以调整范围后重新描述。      │
│ [重新描述]                    │
└────────────────────────────┘
```
